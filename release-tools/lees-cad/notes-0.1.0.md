## Lee's CAD 0.1.0

首个公开版本，提供 Windows x64 与 macOS Apple Silicon 的原生桌面应用及 CLI。

- 基础二维绘图、编辑、图层、文字标注、静态块和布局工作区。
- DXF/DWG 读写基础及 PDF/SVG/PNG 输出；支持简体中文和英文界面。
- 深色蓝图应用图标，统一替换 Windows、macOS 与窗口资源。
- 修正关于窗口中继承的来源描述，准确说明独立维护与原生桌面定位；同版重发后请重新下载、校验并手动安装旧包的替代版本，应用内更新不会提示同版本修正。
- 保存前评估外部数据风险；不可完整保留的数据拒绝写出，已有完整图纸按原始字节轮替 `.bak`。
- 主动检查双源更新，校验独立发行清单、Minisign、大小、SHA-256 和原生包身份。

### 下载与安装

Windows 安装版选择 `.msi`，便携版选择 `-portable.zip`；CLI 随包提供。Mac 首次安装选择 `.dmg`，CLI 选择独立 ZIP，`.app.tar.gz` 用于应用内更新。每个二进制包均提供独立 `.minisig`；使用 `SHA256SUMS` 核对下载内容。具体步骤见仓库 README。

Windows 使用自签证书，不自动导入系统信任库；macOS 为 ad-hoc 签名，未做 Apple 公证。仅本次列出的两种架构经过发行构建检查，最低系统版本、干净系统安装及故障恢复仍需扩展实机验收。

### 已知限制

当前不保证任意工程图无损回存或完整 AutoCAD 功能。原生多重引线、动态块、完整外参管理、自动保存与崩溃恢复仍有缺口；某些外部扩展数据会导致保存/转换被拒绝。重要图纸请保留原件，使用副本并手动保存。

本版本开始使用独立版本号 0.1.0；此前 0.5.0 是开发基线编号，未公开发行。开发包用户应手动安装本版本，更新器不会将其视为更高版本。
