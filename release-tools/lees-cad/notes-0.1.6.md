Lee's CAD 0.1.6 完善外部参照、文字排版与关联填充，增强中文图纸互通和保存保护。

- 📝 支持 MTEXT 静态/动态分栏，完善多重引线分支编辑。
- 🗂️ 外部参照支持附着、重载、改路径、绑定、分离及嵌套加载。
- ✏️ 支持椭圆属性与样条权重编辑，完善关联填充边界及复制随动。
- 🔤 支持更多中文及其他旧编码名称，改善 DXF/DWG 文字互通。
- 🖨️ 优化打印窗口内的填充与文字输出，缺少外部打印样式时明确提示。
- 🛡️ 改善 Windows 保存时的文件权限/备用数据流保留，修复图层恢复、原生回存及保存失败处理问题。

Windows 仅提供 MSI（含桌面应用与 CLI）；macOS 提供 DMG、应用更新包和 CLI ZIP。复杂扩展数据及不支持的编辑仍按保护规则拒绝；常规出图按实际图框选择打印窗口。原生 MULTILEADER、XCLIP/卸载及部分高级外参语义仍有缺口。
