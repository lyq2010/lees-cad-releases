- 🏠 无文件启动直接进入首页，不再自动新建空白图纸；选项移到“文件”菜单，Ctrl+, 正常打开。
- 🛠️ 接通外参管理、块属性查看与同步、快速计算、文档与布局列表，补齐多处菜单输入和错误反馈。
- 🛡️ 修复图层恢复丢失新增定义、部分编辑绕过锁定图层、单位草稿串图和快速选择缓存过期；限制计算递归并拒绝退化角度。
- ⚡ 减少空闲唤醒，复用显示几何与 GPU 缓冲，关闭图纸及时释放缓存，降低多页 PDF、字体和截图的内存占用。

- 📦 macOS CLI 随应用包提供，Agent 可直接通过完整路径调用，不修改 PATH；停止新增独立 CLI ZIP。

Windows 仅提供 MSI，包含桌面应用、CLI、共享字体与许可。macOS 提供 DMG 和应用更新 TAR，CLI 位于 `.app/Contents/MacOS/lees-cad-cli`，共享字体位于 `Contents/Resources/fonts/`，请保留完整应用包。

复杂扩展数据及不支持的编辑仍按保护规则拒绝；原生 MULTILEADER、XCLIP/卸载及部分高级外参语义仍有缺口。macOS 使用 ad-hoc 签名，非 Developer ID 或 Apple 公证；安装升级与系统信任不由自动构建门禁代验。
