Lee's CAD 0.1.1 改善复杂 DWG 保存与中文提示。

- 编辑 DWG 时保留完整原生源数据库，只合并实际编辑差异；原有字典、XData、扩展字典、材质及未修改的代理数据随原生 DWG 回存，并在写出后重新读取校验。
- 未编辑的 DWG 可保持原始文件字节；无法安全表达的编辑或回读不一致仍拒绝保存，保护原件及未保存修改。代理数据保留不等于可编辑其插件内部语义；转存 DXF 仍按该格式的保真能力判断。
- 补齐命令提示、保存错误、动态输入、关闭确认及各设置/样式窗口的中文显示，保留用户文件名和程序接口原文。
- Windows 仅提供 MSI，随包包含桌面程序、CLI 和许可；macOS DMG、应用更新 TAR 和 CLI ZIP 保留。

Windows x64 与 macOS Apple Silicon 分别通过发行门禁、构建和包签名校验。Windows 使用维护者自签证书，macOS 使用 ad-hoc 签名。签名不代表已获得系统信任或 Apple 公证。格式兼容按具体图纸和编辑操作验证，不承诺任意工程图的完整 AutoCAD 语义。
